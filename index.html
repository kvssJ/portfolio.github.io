About me

Hi there! My name is K.V. Siva Surya. I'm a senior at Timpany School, Visakhapatnam, with a deep interest in electrical engineering. Anti-veering assistive wearable for visually impaired swimmers.

Over the past few months, I've been working on making an easy-to-use and cheap assistive wearable that can help blind swimmers swim in a straight line path without facing issues like path deviations. In building this project, I've used onshape for CAD design, KiCad for PCB design and an esp32 with C++ to program it.

A 5x6 RGB LED matrix

To learn more about multiplexing and digital electronics, I made an RGB LED matrix that uses multiplexing for LED control and Bit Angle Modulation for brightness control. I used multiple npn and pnp transistors to control and turn on a specific LED and used the inbuilt hardware timers of an arduino nano for the actual display and control of the matrix.

A GUI to control and animate an LED matrix

After making the LED matrix, to easen the control and programming of the matrix, I also used the tkinter library in python to create a Graphical User Interface to create and upload frames and create animations.

A 4-bit adder and subtractor

Hoping to learn more about digital electronics, I used a shift register to input two 4 bit binary numbers and perform addition or subtraction based on an external switch. For this, I used full adder circuits for 4 bit addition and a circuit using XOR gates and a SN74HC85N magnitude comparator IC to find the two's complement of both binary numbers and subtract the smaller number from the larger one.

A real-time gesture controlled bionic hand

I created a model of a bionic hand that tracks hand landmarkers and uses the relative distances between certain points to imitate real-time hand movements on a servo-controlled model of a bionic hand.
